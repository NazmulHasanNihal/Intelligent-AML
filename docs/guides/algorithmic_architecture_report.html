Data Engineering

2. Layer 1: Universal Graph Schema & DuckDB Ingestion Engine

Banking data suffers from severe fragmentation: cryptocurrency ledgers use hash addresses and block numbers; mobile money logs use steps and account strings; core banking engines use SWIFT BIC codes and ISO 8601 timestamps. Layer 1 solves this via a Universal Heterogeneous Graph Schema backed by DuckDB's zero-copy streaming engine.

Node Specification: nodes.parquet Schema
# Schema of data/outputs/graph_data/{dataset}/nodes.parquet node_id: Utf8 # Universal string identifier node_type: Categorical # 'Account' | 'User' | 'Device' | 'Institution' feat_0..N: Float32 # Raw domain attributes (0 to 168 dims) label / y: Int64 # -1: Unknown, 0: Licit, 1: Illicit (AML Flag)

Preserves entity heterogeneity without schema collapse, enabling type-specific linear transformations in Layer 2.

Edge Specification: edges.parquet Schema
# Schema of data/outputs/graph_data/{dataset}/edges.parquet src: Utf8 # Originating node identifier dst: Utf8 # Terminating node identifier edge_type: Categorical # 'Transaction' | 'IP_Connection' | 'Shared_Ownership' ts: Float64 # Unified continuous epoch seconds delta_t: Float32 # Time elapsed since node's prior transfer burst_score:Float32 # Sliding-window velocity deviation

Normalizes continuous-time deltas and rolling window bursts into vectorized edge tensors.

DuckDB Streaming Memory Guarantee: The ingestion pipeline enforces an 8 GB memory limit (DUCKDB_MEMORY_LIMIT_GB = 8) with an out-of-core spill directory (.duckdb_spill). This enables processing massive datasets like Elliptic v2 (49.0M nodes, 196.0M edges) on standard commodity hardware without memory exhaustion.

3. Spatiotemporal Invariants, Wavelet Descriptors & Taint Diffusion

Before passing graphs to the neural network, Layer 1 automatically extracts 12 deterministic topological invariants per node to capture structuring, money mule pass-through velocity, and circular wash trading.

1. Bi-Directional PPR Taint Contagion

Propagates risk forward along peeling chains and backward along funding originators:

\mathbf{p}_{\text{fwd}} = (1-\alpha) P^T \mathbf{p}_{\text{fwd}} + \alpha \mathbf{s}_{\text{seed}} \\ \mathbf{p}_{\text{bwd}} = (1-\alpha) P \mathbf{p}_{\text{bwd}} + \alpha \mathbf{s}_{\text{seed}} \\ p_{\text{combined}} = 0.60 p_{\text{fwd}} + 0.40 p_{\text{bwd}}
Cold-start fallback uses degree outliers when ground-truth seeds are absent.
2. Haar Wavelet Descriptors ChronoWave

Decomposes temporal inter-arrival times ($\Delta t$) into low-frequency and high-frequency wavelets:

DWT_{\text{approx}} = \frac{\Delta t_k + \Delta t_{k-1}}{\sqrt{2}} \\ DWT_{\text{detail}} = \frac{|\Delta t_k - \Delta t_{k-1}|}{\sqrt{2}}
DWT approx detects dormant multi-year layering; DWT detail detects rapid 24h smurfing bursts.
3. AML Graphlet Motifs Topology

Mines circular wash trading loops and pass-through flow ratios:

\text{PassThrough} = 1 - \frac{|f_{\text{in}} - f_{\text{out}}|}{f_{\text{in}} + f_{\text{out}} + \epsilon} \\ \text{PeelingRatio} = \frac{f_{\text{out}}}{f_{\text{in}} + \epsilon} \\ \text{Motif Cycle-3} = u \to v \to w \to u
Sybil-resistant effective degree counts only transfers ≥ $10 to ignore dust attacks.

4. Layer 2: BurstAwareHGT Dynamic Heterogeneous Graph Convolution

Standard GNNs (GCN, GraphSAGE, GAT) assume static, homogeneous graphs, suffering catastrophic failure in financial networks due to temporal invalidity, relational collapse, and adversarial camouflage. The BurstAwareHGTConv layer introduces three critical mathematical innovations:

1. Logarithmic Harmonic LUT Time Encoding

Encodes continuous time gaps $\Delta t \in [0, 100,000+]$ without saturation via a 4,000-entry logarithmic harmonic look-up table:

\Phi(\log(1 + \Delta t)) = \left[ \sin(\omega_k \log(1+\Delta t)), \cos(\omega_k \log(1+\Delta t)) \right] \\ \mathbf{k}_{j,\text{time}} = \mathbf{k}_j + W_{\text{time}} \Phi(\Delta t)
2. Anti-Camouflage Gate Robustness

Fraudsters connect to legitimate high-degree nodes to disguise their embeddings. The anti-camouflage gate prunes deceptive edges:

G_{\text{cam}} = \text{floor}_{\text{cam}} + (1 - \text{floor}_{\text{cam}}) \cdot \sigma\left(\cos(\mathbf{q}_i, \mathbf{k}_{j,\text{time}}) \cdot \text{softplus}(\gamma)\right) \\ \hat{\alpha}_{ij} = \text{Softmax}_j\left(\frac{\mathbf{q}_i^T \mathbf{k}_{j,\text{time}}}{\sqrt{d_k}} \cdot G_{\text{cam}}\right)
3. Dual-Resolution Decay Burst Modeling

Multi-head attention divides attention heads into fast and slow velocity bands:

\text{Fast Heads: } w_{\text{fast}} = (w_{\text{min}} + (1-w_{\text{min}})e^{-\lambda_{\text{fast}}\Delta t})(1 + \beta_{\text{fast}}\tanh(B)) \\ \text{Slow Heads: } w_{\text{slow}} = (w_{\text{min}} + (1-w_{\text{min}})e^{-\lambda_{\text{slow}}\Delta t})(1 + \beta_{\text{slow}}\tanh(B)) \\ \mathbf{m}_{ij} = \mathbf{v}_j \cdot \hat{\alpha}_{ij} \cdot w_t

Multi-Moment Higher-Order Subnetwork Ego-Pooling

To provide gradient-boosted decision trees with rich structural neighborhood distributions, Layer 2 extracts 7 statistical moments from the GNN latent embedding space:

1st Moment & Contrast

Ego-Mean: $\mu_{\mathcal{N}(u)}$ (peer risk)
Ego-Contrast: $\mathbf{z}_u - \mu_{\mathcal{N}(u)}$ (anomaly deviation)

2nd Moment (Dispersion)

Ego-Std: $\sigma_{\mathcal{N}(u)} = \sqrt{\text{mean}(\mathbf{z}^2) - \mu^2}$
Measures diversity of counterparty behavior.

Extreme Bounds & p95

Ego-Max / Ego-Min / Ego-p95: Isolates the highest-risk counterparty while protecting super-nodes from variance dilution.

Cold-Start Centroid

When $d(u) = 0$, substitutes global population centroid $\mathbf{z}_{\text{global}}$ and sets binary flag to prevent zero-vector bias.

5. Data Augmentation: Constrained GraphSMOTE & Latent GraphGAN

Because real-world money laundering represents less than 0.1% of transactions, standard training causes severe model bias. Intelligent-AML implements two complementary graph augmentation strategies:

Constrained Safe-Manifold GraphSMOTE Interpolation

Standard SMOTE interpolates randomly across minority instances, causing non-convex manifold corruption. Our constrained GraphSMOTE enforces:

  • Cosine Similarity Threshold (≥ 0.60): Interpolates only between topologically similar fraud nodes.
  • Sampled Incident Edge Attachment: Limits attached edges to max 10 to prevent artificial graph density explosion.
  • Continuous Gaussian Temporal Jitter: $\Delta t_{\text{synth}} = \Delta t_{\text{parent}} \cdot (1 + 0.05 \cdot \mathcal{N}(0, 1))$.
Multi-Scale InfoNCE Temporal Contrastive Pretraining Self-Supervised

Pretrains the GNN backbone before supervised fine-tuning using dual-view stochastic augmentations:

\mathcal{L}_{\text{InfoNCE}} = -\log \frac{\exp(\text{sim}(\mathbf{z}_{u}^{(1)}, \mathbf{z}_{u}^{(2)}) / \tau)}{\sum_{v} \exp(\text{sim}(\mathbf{z}_{u}^{(1)}, \mathbf{z}_{v}^{(2)}) / \tau)}

Learns robust spatiotemporal representations that are invariant to artificial velocity noise.

Uncertainty Calibration

7. Layer 3: Soft-Mondrian Topology-Stratified Conformal Prediction

Standard machine learning produces uncalibrated probabilities that lead to massive false alert rates. Intelligent-AML applies Mondrian Topology-Stratified Inductive Conformal Prediction, providing mathematically proven, distribution-free error bounds:

\mathbb{P}(Y \in \mathcal{C}(X)) \ge 1 - \alpha \quad \text{for any arbitrary underlying data distribution}
Stratum 0: Cold-Start Strata

Accounts with $d=0$ (newly registered or burner accounts). Uses conservative threshold bound.

Stratum 1: High-Degree Hubs Strata

Accounts with $d \ge 50$ (Exchanges, Merchants). Calibrates tight bounds against high transaction noise.

Stratum 2: Structuring Rings Strata

Accounts with $\text{PassThrough} \ge 0.80$ or $\text{Cycles} > 0$. Prioritizes high recall on laundering loops.

Stratum 3: Standard Accounts Strata

Standard retail accounts adhering to nominal financial velocity.

Soft-Continuous Stratum Blending & Operational Decision Sets

To eliminate threshold flapping across sharp boundaries, C-STGB continuously interpolates effective quantiles: $q_{\text{eff}}(x) = \sum_{k=0}^3 \mu_k(x) q_k$. The model outputs one of three definitive operational actions:

$\mathcal{C}(x) = \{0\}$ — Confident Licit

Probability is bounded well below $q_{\text{eff}}$. Transaction is auto-approved instantly with zero compliance friction.

$\mathcal{C}(x) = \{1\}$ — Mandatory SAR Alert

Probability exceeds $1 - q_{\text{eff}}$. Triggers immediate asset freeze and escalates to the FIU filing desk.

$\mathcal{C}(x) = \{0, 1\}$ — Review Queue

Prediction is uncertain. Routed to senior AML compliance investigators for enhanced due diligence (EDD).
