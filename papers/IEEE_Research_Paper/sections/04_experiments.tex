\end{enumerate}

\subsection{Temporal Partitioning \& Zero-Leakage Audit}
\label{sec:temporal_partitioning}
To prevent temporal lookahead bias and evaluate realistic forward inductive deployment, all datasets follow a strict 4-way chronological partition:
\begin{itemize}
    \item \textbf{Parameter Training Split ($\mathcal{D}_{\text{train}}$, 60\%):} Used strictly for updating neural parameters $\Theta$.
    \item \textbf{Validation Split ($\mathcal{D}_{\text{val}}$, 10\%):} Used exclusively for early stopping and Bayes decision threshold calibration ($\tau^*$).
    \item \textbf{Calibration Split ($\mathcal{D}_{\text{cal}}$, 10\%):} Dedicated holdout split used solely for computing non-conformity quantiles $\hat{q}^{(0)}, \hat{q}^{(1)}$ (0 weight updates, 0 threshold selection).
    \item \textbf{Forward Out-of-Time Test Split ($\mathcal{D}_{\text{test}}$, 20\%):} Strictly out-of-time future horizon for reporting final performance.
\end{itemize}

For discrete UTXO graphs (e.g., Elliptic-v1 with 49 timesteps), Timesteps 1--30 (61.2\%) form $\mathcal{D}_{\text{train}}$, Timesteps 31--34 (8.2\%) form $\mathcal{D}_{\text{val}}$, Timesteps 35--38 (8.2\%) form $\mathcal{D}_{\text{cal}}$, and Timesteps 39--49 (22.4\%) serve as $\mathcal{D}_{\text{test}}$. Continuous transaction stream datasets (PaySim, SAML-D, IBM-AMLSim, Ethereum) follow an identical non-overlapping timestamp horizon partition ($t_0 \to t_{\text{train}} \to t_{\text{val}} \to t_{\text{cal}} \to t_{\text{test}}$).

An automated topological audit confirms that $0.0\%$ of entities evaluated during the test horizon $\mathcal{D}_{\text{test}}$ have overlapping label assignments or future connectivity during model training on $\mathcal{D}_{\text{train}}$. Causal PageRank taint seeds ($\mathbf{s}_{\text{seed}}$) are derived strictly from confirmed illicit entities within source training data, guaranteeing 0.0\% test-time target label access.

\subsection{Baseline Architectures \& Fair Optimization Protocol}
\label{sec:baselines_protocol}
We benchmark C-STGB against 11 distinct baseline architectures spanning six canonical model paradigms:
\begin{enumerate}
    \item \textbf{Tabular Tree Ensembles:} XGBoost~\cite{chen2016xgboost} and CatBoost~\cite{prokhorenkova2018catboost}.
    \item \textbf{Spatial GNNs:} GCN~\cite{kipf2017semi}, GraphSAGE~\cite{hamilton2017inductive}, GAT~\cite{velickovic2018graph}, and GIN~\cite{xu2019powerful}.
    \item \textbf{Heterogeneous GNNs:} Vanilla HGT~\cite{hu2020heterogeneous} and Johannessen \& Jullum~\cite{johannessen2023predicting}.
    \item \textbf{Adversarial Fraud Detectors:} CARE-GNN~\cite{dou2020enhancing}.
    \item \textbf{Dynamic Snapshot Models:} EvolveGCN~\cite{pareja2020evolvegcn}.
    \item \textbf{Continuous Temporal GNNs:} TGN~\cite{rossi2020temporal}.
\end{enumerate}

To ensure complete methodological fairness and avoid baseline crippling, all baseline architectures received an identical extensive hyperparameter search budget of $N=50$ trials over $\mathcal{D}_{\text{val}}$ and were evaluated using their optimal validation-tuned Bayes decision thresholds $\tau^*$ (rather than default uncalibrated $\tau=0.50$, whose comparative progression is disentangled in Table~\ref{tab:multi_ablation}).

\subsection{Evaluation Metrics \& Statistical Testing Protocol}
\label{sec:metrics_protocol}
Under extreme class imbalance ($\pi \ll 0.01$), traditional ROC-AUC is known to yield overly optimistic assessments due to the dominant true negative denominator. Consequently, our primary decision metrics are:
\begin{enumerate}
    \item \textbf{Precision-Recall AUC (PR-AUC):} Quantifies minority class precision-recall trade-offs independent of decision thresholds.
    \item \textbf{Macro F1-Score \& Minority Recall:} Measures balanced harmonic utility across both legitimate and illicit classes under tuned threshold $\tau^*$.
    \item \textbf{Conformal Prediction Set Efficiency ($\mathbb{E}[|\Gamma(X)|]$):} Evaluates the tightness of prediction sets, ensuring coverage guarantees are achieved non-trivially.
\end{enumerate}

Statistical significance is evaluated using non-parametric two-sided Wilcoxon Signed-Rank Tests against key baselines and global Friedman Rank-Sum Tests with average ranks across the 13 benchmark datasets.

\subsection{Class-Conditional Conformal Risk Control \& Queue Triage}

Crucially, the high coverage guarantee ($99.12\%$ macro-average) is achieved with optimal prediction set efficiency: across all $11.42$ million test transactions, singleton decisive prediction sets ($|\Gamma(X)| = 1$) account for $99.50\%$ of volume (Tier 1 + Tier 3), while ambiguous abstention sets ($|\Gamma(X)| = 2$, Tier 2) comprise only $0.50\%$. The empty prediction set rate $\mathbb{P}(\Gamma(X) = \emptyset)$ is verified to be exactly $0.00\%$, yielding an average prediction set size of $\mathbb{E}[|\Gamma(X)|] = 1.0050$, confirming that coverage guarantees are non-trivial and operationally tight.

Under its Hierarchical Fast-Path mode, C-STGB achieves a streaming single-event latency of $0.45$\,ms (P99: $0.82$\,ms) and $428$\,MB peak VRAM footprint, comfortably fulfilling sub-10\,ms enterprise payment authorization SLAs at $31,200\text{ tx/s}$ throughput. Under its full multi-scale GNN configuration, streaming latency is $2.10$\,ms ($3.30 \pm 0.20$\,ms for batch size 64) with $894$\,MB VRAM.

An itemized latency profiling on live payment streams reveals the fine-grained per-event computational budget under Fast-Path mode: (i) Ingestion and 12-D invariant calculation via DuckDB/Arrow ($0.11$\,ms); (ii) Dynamic Top-$K$ ($K \le 15$) causal ego-subgraph retrieval ($0.18$\,ms); (iii) Temporal GNN and evidence-adaptive gate forward pass ($0.12$\,ms); and (iv) Conformal calibrated triage routing ($0.04$\,ms), culminating in a total end-to-end processing latency of $0.45$\,ms per transaction, as detailed in Supplementary Table~S9.
